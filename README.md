# Class Activity Recap

## 1. GitHub Repository and Branch Setup

At the beginning of the class, the teacher asked us to open GitHub and create a repository for the course. We were then instructed to create two additional branches named `tp` and `course`, alongside the default `main` branch.

After that, the teacher checked our GitHub accounts and activities to make sure we had created the repository and the required branches correctly. This activity helped us practice the basic use of GitHub and understand how branches can be used to organize our coursework.

## 2. Reviewing Programming Terminology

After checking our GitHub activities, the teacher opened the lecture slides and gave us some time to read and understand the content.

The teacher then started an interactive activity by asking students to explain different programming terms related to code structure and architecture, such as variables, functions, classes, constants, packages and etc.

Students took turns answering the questions and explaining their understanding of each term. After one student answered, the teacher moved on to another student to discuss the next keyword. This activity encouraged us to think independently, share our knowledge, and learn from one another.

During this activity, I was asked to explain the meaning of a **constant** in programming, particularly in Python. I understood it as a value that is intended to remain unchanged throughout the program. For example, the mathematical constant π (pi) can be represented by a variable such as `PI`. In Python, constants are usually indicated by uppercase names, although Python does not strictly prevent their values from being changed.

## 3. Writing Clean and Maintainable Code

In the next part of the lesson, we discussed how to organize our code to make it easier to understand, maintain, and debug.

The teacher introduced different techniques and methods for avoiding messy or overly complex code. These practices are important not only for the original programmer but also for other developers who may need to read, modify, or maintain the code after a long period of time.

I understood that writing good code is not just about making a program work. It is also about making the code clear, organized, and easy to maintain, so that errors can be identified and fixed more efficiently.

## 4. What I Learned

From these class activities, I learned the importance of organizing coursework using GitHub branches, understanding fundamental programming terminology, and writing clean, maintainable code.

The interactive question-and-answer activity also encouraged me to think about programming concepts and explain them in my own words. Overall, the lesson helped me recognize that good programming involves both solving problems and structuring code in a way that makes it easier for ourselves and others to understand and maintain.
